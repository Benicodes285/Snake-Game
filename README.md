# 🐍 Snake Game

A simple and interactive Snake Game developed using **Python** and **Tkinter**.

The player controls the snake using the arrow keys, eats the food to grow, and tries to avoid hitting the walls or itself.

## 🚀 Features

- 🎮 Arrow-key controls
- 🍎 Random food generation
- 🐍 Snake growth after eating food
- 💥 Wall collision detection
- 💥 Self-collision detection
- 🔄 Restart Game button
- 🖥️ Simple graphical interface using Tkinter

## 🛠️ Technologies Used

- Python
- Tkinter
- Random module
